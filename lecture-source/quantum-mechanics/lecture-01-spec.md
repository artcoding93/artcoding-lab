## 0-1. 승인된 커리큘럼 개편과의 정합성 (필수)

- 전체 교육과정 슬로건은 **'양자 세계에서 양자컴퓨팅까지'**이며 **제1강 제목이 아니다**.
- 제1강의 확정 제목은 **'양자역학은 왜 탄생했을까?'**, 영문 제목은 **'Why Was Quantum Mechanics Born?'**이다. 로드맵 데이터와 실제 강의 페이지의 제목을 일치시킨다.
- 기존 `src/data/quantum-roadmap.ts`의 제1강 ID **`what-is-qc`**와 기존 slug는 그대로 유지한다. 실제 slug 문자열은 프로젝트에서 확인하고 새로 추측하지 않는다.
- 제1강 유형은 **A(개념 중심)**, 표시 난이도는 **고교**, 강의 상태는 별도 승인 전까지 **`planned`**로 유지한다.
- 제1강 학습 목표는 고전물리학의 한계, 흑체복사, 광전효과, 에너지 양자화의 이해와 양자컴퓨팅과의 연결이다.
- 개편된 Part I의 순서는 ① 양자역학 탄생 ② 빛과 전자/이중슬릿 ③ 중첩 ④ 측정 ⑤ 얽힘 ⑥ 비트와 큐비트이다. 이 문서에서는 **제1강만 구현**하며 다른 강의의 순서를 재변경하지 않는다.
- 제2강은 이중슬릿 실험의 본격적 설명을 담당한다. 제1강의 이중슬릿 도식은 예고 수준으로 유지하고 중복되는 상세 시뮬레이션을 추가하지 않는다.
- `lecture-source/quantum-mechanics/lecture-01.md`와 `lecture-01-spec.md`를 원본 기준으로 사용한다. 사이트 콘텐츠와 로드맵에 이미 반영된 개편 사항이 있으면 중복 수정하지 않는다.
- 로드맵의 A/B/C 유형 칩 및 학습 목표 표시는 개편 작업의 범위이다. 제1강 구현 시 공통 `LearningRoadmap.astro`나 다른 주제 로드맵을 불필요하게 수정하지 않는다.

3. 현재 사이트의 스타일 토큰, 반응형 구성, 다크모드, 시각화 컴포넌트 재사용 가능성을 확인한다.

5. **최초 실행에서는 구현 계획만 제시하고, 사용자 승인 전 파일을 수정하지 않는다.**
6. 작업 트리에 다른 분야(FEM 포함)의 삭제/미커밋 변경이 있으면 복원·삭제·커밋하지 않고 그대로 둔다.

## 2. 콘텐츠 통합

- 원고의 8개 절, 표, 수식, 계산 예제, 5개 그림 및 2개 시각화를 모두 구현한다.
- Markdown 또는 MDX 선택은 프로젝트 기존 패턴에 따른다. 수식은 KaTeX에서 검증한다.
- `E=hf`, `E_n=nhf`, `E_photon=hf`, `K_max=hf-phi`, 큐비트 상태식의 표기와 의미를 보존한다.
- 이 강의는 Python 실습과 연습문제를 추가하지 않는다.
- 사이트의 교육과정 제목이 개편되었더라도 원고의 확정 제목과 학습 목표를 우선한다. 데이터/페이지 제목 충돌은 보고한다.
- 제1강 공개는 별도 승인 후에만 `planned` 상태를 변경한다. 실제 페이지 파일이 생겼다는 이유만으로 자동 공개하지 않는다. 다른 강의의 공개 상태는 변경하지 않는다.

## 3. 시각화 상세 명세

### 그림 1 — 고전역학
- 포물선 운동과 행성 궤도 도식. 수치 정확성보다 개념 설명에 집중하되 오해를 유발하는 표시 금지.

### 그림 2 — 열복사
- 가열된 금속의 색 변화. 온도와 색상의 관계를 과도하게 단정하지 말 것.

### 시각화 1 — 흑체복사 비교 (가능하면 인터랙티브)
- x축: 파장 `lambda` (nm 또는 μm, 단위 명시), y축: 파장당 분광 복사휘도 `B_lambda` (단위 명시).
- 같은 온도에서 Planck와 Rayleigh–Jeans 법칙 비교.
- Planck: `B_lambda = 2*h*c^2/lambda^5 / (exp(h*c/(lambda*k_B*T))-1)`.
- Rayleigh–Jeans: `B_lambda = 2*c*k_B*T/lambda^4`.
- SI 단위를 내부 계산에 사용. 파장 100~3000 nm, 온도 기본 5500 K 등은 UI에 맞게 조정 가능.
- 파장 0을 절대 계산하지 않는다. 지수 오버플로 및 극단적 값에 대한 수치 안정성 확보.
- 고전 곡선이 짧은 파장에서 발산하는 특징을 보여주되 그래프 자동 스케일 때문에 Planck 곡선이 사라지지 않도록 표시 범위/설명을 설계한다.
- 가능하면 온도 슬라이더를 제공하되 기본값만으로도 충분히 이해 가능해야 한다.
- 차트의 범례, 축, 캡션, 스크린리더 설명을 포함한다.

### 시각화 2 — 연속 에너지와 양자화된 에너지
- 좌측: 연속 범위, 우측: `0, hf, 2hf, 3hf, ...` 에너지 준위.
- '모든 양자계의 준위가 등간격은 아님'이라는 주석을 명시한다.
- 필요 시 `f` 슬라이더로 간격 변화 표현. 단순 정적 SVG로도 충분.

### 그림 3 — 광전효과
- 입사 광자, 금속, 방출 전자, 일함수 `phi`를 명확하게 구분.
- 광자의 에너지 `hf`가 일함수보다 작으면 단일 광자 과정에서 전자 방출이 없음을 표시.
- 추가 인터랙션을 넣는다면 광자 에너지와 일함수 조절, `K_max = max(0, hf-phi)` 시각화를 제공. 단, 미방출 상태에서 `K_max=0`을 실제 방출 전자의 운동에너지로 잘못 표현하지 말고 '전자 방출 없음'으로 표시.

### 그림 4 — 파동-입자 이중성 (제2강과 역할 분리)
- 이중슬릿 간섭 패턴과 개별 검출 점의 축적을 구분하는 도식. 한 번의 광자 검출 자체가 연속 간섭무늬가 아님을 명시. 제1강에서는 정적 개념도로 충분하며 슬릿 간격·파장 조절 등 상세 인터랙션은 제2강에서 구현한다.

### 그림 5 — 비트와 큐비트
- 고전 비트 0/1, 큐비트 상태벡터와 블로흐 구면 개념도.
- 구면 그림은 설명용이며 중첩이 곧 '측정 시 0과 1을 동시에 읽는 것'이라는 오해를 유발하지 않도록 한다.

## 4. 디자인과 접근성

- 기존 Starlight 스타일 및 색상 체계를 재사용하고, 모바일 360px 이상에서 가로 넘침을 방지한다.
- 제목/소제목/표/캡션의 계층을 일관되게 유지한다.
- 수식이 좁은 화면에서 잘리지 않도록 가로 스크롤 또는 반응형 처리한다.
- 그림마다 대체 텍스트 또는 적절한 `aria-label`, 그래프는 텍스트 설명과 범례 제공.
- 다크모드에서 글자·축·선의 대비 확인.
- 시각화 라이브러리는 프로젝트 기존 의존성을 우선하고 신규 패키지 설치는 필요한 경우 사전 설명한다.

## 5-1. 사이트 개편 작업과의 충돌 방지

- 로드맵 개편을 먼저 완료한 뒤 제1강 구현을 진행한다. 이미 변경된 제목·난이도·학습 목표를 덮어쓰지 않고 확정 원고와 대조한다.
- `quantum-simulator-project.ts`의 `lectureIds` 연결이 제1강 ID 유지로 정상 동작하는지 확인한다.
- 공통 스타일, 다른 분야의 강의, 기존 FEM 파일 삭제 상태는 변경하지 않는다.
- 제1강 페이지의 URL은 기존 slug 기반으로 유지하고, 공개 여부는 사용자가 별도 결정한다.

## 6. 완료 조건

- 8개 절, 표 2개, 주요 수식과 계산 예제, 그림 5개, 시각화 2개가 빠짐없이 표시됨.
- 로드맵과 강의 페이지의 제목/영문 제목이 확정 원고와 일치하고, ID·slug가 유지됨.
- 제1강은 고교·A형으로 표시되며 제2강의 이중슬릿 상세 내용을 앞당겨 중복 구현하지 않음.

- 기존 Quantum 목차 및 다른 주제의 페이지에 회귀 오류가 없음.
- 원고가 임의로 요약되거나 학습 난이도가 높아지지 않음.
