## 프로젝트 소개

FEM 강의에서 배운 개념을 하나의 **Python 기반 2D FEM 솔버**로 직접 구현하는 장기 프로젝트입니다. 각 Phase는 FEM 학습 로드맵의 강의와 연결되어 있어, 강의에서 배운 내용이 곧바로 솔버의 한 부분이 됩니다.

첫 구현 대상은 **2D 정상상태 열전도(Steady-State Heat Conduction) 문제**입니다. 변위·응력처럼 여러 성분을 가진 물리량 대신 온도라는 **단일 스칼라장**을 다루므로, 절점당 미지수가 하나뿐이어서 FEM의 계산 구조(메시 → 요소 행렬 → 조립 → 경계조건 → 풀이)에 집중할 수 있습니다.

$$
-\nabla \cdot (k \nabla T) = Q \quad \text{in } \Omega
$$

- $T$: 온도(구하려는 미지수), $k$: 열전도율, $Q$: 단위 부피당 내부 발열량, $\Omega$: 해석 영역
- 일부 경계에서는 온도를 지정하고(Dirichlet 조건), 나머지 경계에서는 열유속을 지정합니다(Neumann 조건).
- FEM으로 이산화하면 절점 온도 벡터 $\mathbf{T}$에 대한 선형 시스템 $\mathbf{K}\mathbf{T} = \mathbf{F}$가 됩니다. 솔버 프로젝트는 이 $\mathbf{K}$와 $\mathbf{F}$를 직접 만들고 푸는 과정입니다.

## 최종 목표

- 2D 삼각형 메시 생성부터 결과 시각화까지 동작하는 **열전도 FEM 솔버**를 직접 구현하고, 메시 세분화에 따른 오차 감소로 정확성을 검증합니다.
- 같은 계산 구조를 **2D 선형 탄성체(구조해석)** 문제로 확장합니다.
- 솔버를 재사용 가능한 구조로 정리하고 **도메인 분할·MPI·GPU**를 이용한 병렬·분산 계산과 확장성 분석까지 수행합니다.

## 최종 통합 프로젝트

마지막 단계(Phase 6-5, 강의 70 「적응형·병렬 FEM 통합 프로젝트」)에서는 지금까지 만든 요소를 하나로 결합합니다.

1. **적응형 메시 세분화**: 오차 추정값이 큰 영역의 요소만 세분화해 계산 비용 대비 정확도를 높입니다.
2. **병렬·분산 계산**: 도메인 분할과 MPI 통신(Ghost Node 교환)으로 전역 행렬 조립과 풀이를 여러 프로세스에 나눕니다.
3. **성능 분석**: 문제 크기와 프로세스 수를 바꿔 가며 확장성(strong·weak scaling)을 측정하고 보고서로 정리합니다.
