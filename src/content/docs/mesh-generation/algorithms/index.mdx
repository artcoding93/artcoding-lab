논문에서 제안한 알고리즘을 Python으로 직접 구현하고 단계별로 시각화합니다. **외부 메시 생성 라이브러리로 결과를 만드는 것만으로는 재현으로 인정하지 않습니다.** 외부 라이브러리는 결과 검증과 비교에만 사용합니다.

## 재현 기준

| 기준 | 내용 |
|---|---|
| 핵심 알고리즘 구현 | 논문의 핵심 계산을 직접 구현 |
| 입력·출력 명확화 | 입력 형식(점 집합, PSLG, 크기 함수 등)과 출력 메시 구조 정의 |
| 단계별 계산 확인 | 중간 상태를 출력·시각화해 논문의 절차와 대조 |
| 단위 테스트 | pytest로 기하 술어와 핵심 연산 검증 |
| 기하학적 유효성 | 요소 방향, 겹침, 경계 보존, Delaunay 조건 검사 |
| 논문과의 차이 기록 | 원 논문 재현인지 단순화 구현인지, 달라진 부분과 이유 |
| 재현 가능한 환경 | Python·패키지 버전, 난수 시드, 입력 데이터 고정 |

- 기본 도구: NumPy(배열 계산), SciPy(비교·검증용 계산), Matplotlib(시각화), pytest(테스트)
- 성능 문제가 확인되면 프로파일링 후 **병목인 부분만** 최적화합니다. 처음부터 전체를 C++로 작성하지 않습니다.
- 재현 코드는 `public/code/mesh-generation/`에 두고, 리뷰 페이지에는 핵심 코드만 싣습니다.
