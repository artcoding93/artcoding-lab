## 노트 작성 항목

| 항목 | 내용 |
|---|---|
| 작성일 | YYYY-MM-DD |
| 관련 논문·알고리즘 | Paper Library와 Algorithm Reproduction의 ID로 연결 |
| 문제 정의 | 무엇을 확인하려 하는가 |
| 관찰 내용 | 실제로 본 현상 (재현 코드·실험에서 얻은 것) |
| 연구 가설 | 검증 가능한 형태의 주장 |
| 실험 계획 | 형상, 지표, 비교 대상 |
| 결과 | 실행한 실험의 실제 결과 |
| 한계 | 결과를 일반화할 수 없는 조건 |
| 다음 연구 과제 | 이어서 할 일, 관련 노트 |
