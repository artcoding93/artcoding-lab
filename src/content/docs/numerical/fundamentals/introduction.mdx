## 1.1 수치해석이란 무엇인가?

### 1.1.1 수치해석의 정의

{/* '**…)**은'은 CommonMark 강조 규칙(닫는 ** 앞이 문장부호, 뒤가 글자)상 굵게 처리되지 않아 <strong>으로 표기한다 */}
<strong>수치해석(Numerical Analysis)</strong>은 수학적 문제의 해를 수치적으로 근사하는 알고리즘을 연구하고, 계산 결과의 정확성과 신뢰성을 분석하는 학문입니다.

수학에서는 방정식이나 공식을 이용하여 정확한 해를 구할 수 있는 경우가 많습니다. 그러나 현실의 복잡한 문제에서는 정확한 해를 구하기 어렵거나, 해를 표현할 수 있어도 계산이 복잡할 수 있습니다.

수치해석은 이러한 문제를 컴퓨터로 해결할 수 있도록 수학적 계산 방법을 제공합니다.

수치해석에서 중요한 것은 단순히 계산 결과를 얻는 것이 아니라, **그 결과가 얼마나 정확하고 신뢰할 수 있는지 판단하는 것**입니다.

### 1.1.2 해석적 해법과 수치적 해법

다음 방정식을 생각해 보겠습니다.

$$
x^2-2=0
$$

이 방정식의 양의 해는 다음과 같습니다.

$$
x=\sqrt{2}
$$

이는 정확한 해를 수학적 기호로 표현한 것입니다.

반면 컴퓨터에서는 일반적으로 유한한 정밀도의 근삿값을 사용합니다.

$$
x\approx1.4142135623730951
$$

| 구분 | 해석적 해법 | 수치적 해법 |
|---|---|---|
| 해의 표현 | $\sqrt{2}$ | $1.41421356\ldots$ |
| 접근 방식 | 수학적 유도 | 수치 계산 |
| 결과 | 정확한 기호적 표현 | 근사값 |

해석적 해법과 수치적 해법은 서로 대립하는 방법이 아닙니다. 실제 문제에서는 두 방법을 함께 활용하기도 합니다.

## 1.2 컴퓨터는 수학 문제를 어떻게 해결하는가?

### 1.2.1 수학적 문제에서 계산 결과까지

컴퓨터로 수학적 문제를 해결하려면 문제를 수학적으로 표현하고, 이를 계산 가능한 알고리즘으로 변환해야 합니다.

예를 들어 자동차가 일정한 속도로 이동할 때 이동 거리는 다음과 같이 계산할 수 있습니다.

$$
s=vt
$$

여기서 $s$는 이동 거리, $v$는 속도, $t$는 시간입니다.

하지만 실제 자동차의 속도는 계속 변합니다. 이 경우 시간에 따라 달라지는 속도를 고려해야 하므로 계산이 복잡해집니다.

이처럼 현실 문제를 수학적으로 모델링하고, 필요한 경우 수치 알고리즘을 적용하여 계산하는 것이 수치해석의 기본적인 접근 방식입니다.

### 1.2.2 근사 계산이 필요한 이유

다음과 같은 적분을 생각해 보겠습니다.

$$
\int_0^1 x^2\,dx
$$

이 적분은 해석적으로 계산할 수 있습니다.

$$
\int_0^1 x^2\,dx=\frac13
$$

하지만 복잡한 함수에서는 적분값을 직접 구하기 어려울 수 있습니다.

이때 함수 아래의 면적을 여러 개의 작은 사각형으로 나누어 근사할 수 있습니다.

<RiemannSumExplorer fn="square" a={0} b={1} exact={1 / 3} exactLabel="1/3" nMin={2} nMax={40} n={6}>

계산식: $R_N=\frac1N\sum_{i=1}^N(i/N)^2=\frac{(N+1)(2N+1)}{6N^2}$. 각 사각형의 높이로 오른쪽 끝점의 함수값을 사용하므로, 증가함수인 $x^2$에서는 근사 면적이 실제 면적 $1/3$보다 크게 나타납니다.

</RiemannSumExplorer>

이러한 방법은 수치적분(Numerical Integration)의 기본 아이디어입니다.

사각형의 개수를 늘리면 일반적으로 근사 오차를 줄일 수 있지만, 계산량도 증가합니다.

수치해석에서는 이처럼 **정확도와 계산 비용 사이의 관계**를 함께 고려합니다.

## 1.3 해석적으로 풀기 어려운 문제

### 1.3.1 비선형 방정식의 근 찾기

다음 방정식을 생각해 보겠습니다.

$$
f(x)=x^3-x-2=0
$$

이 방정식은 정확한 대수적 해를 표현할 수 있지만, 실제 계산에서는 수치적 방법을 사용하는 것이 간편합니다.

먼저 두 지점에서 함수값을 계산합니다.

$$
f(1)=-2,\qquad f(2)=4
$$

함수는 연속이고 두 지점에서 부호가 서로 다르므로, 사잇값 정리에 의해 구간 $(1,2)$ 안에 적어도 하나의 근이 존재합니다.

이 사실을 이용하면 근이 포함된 구간을 반복적으로 좁혀 갈 수 있습니다.

### 1.3.2 이분법(Bisection Method)

이분법은 근이 포함된 구간을 절반씩 나누어 근사해를 계산하는 알고리즘입니다.

초기 구간을 $[a,b]$라고 하면 중점은 다음과 같습니다.

$$
m=\frac{a+b}{2}
$$

중점에서 함수값을 계산하고, 함수값의 부호를 이용해 근이 포함된 절반 구간을 선택합니다.

/>

첫 번째 중점은 다음과 같습니다.

$$
m_1=\frac{1+2}{2}=1.5
$$

$$
f(1.5)=-0.125
$$

따라서 근은 구간 $[1.5,2]$ 안에 존재합니다.

같은 과정을 반복하면 다음과 같은 결과를 얻습니다.

| 반복 | 중점 $m$ | 함수값 $f(m)$ |
|---|---:|---:|
| 1 | 1.500000 | -0.125000 |
| 2 | 1.750000 | 1.609375 |
| 3 | 1.625000 | 0.666016 |
| 4 | 1.562500 | 0.252197 |
| 5 | 1.531250 | 0.059113 |

반복할수록 근이 포함된 구간이 좁아집니다.

이분법으로 구한 근사해는 다음 값에 접근합니다.

$$
\boxed{x\approx1.5213797068}
$$

이분법의 수렴성과 오차 분석은 이후 비선형 방정식 강의에서 자세히 학습합니다.

## 1.5 수치해석의 핵심 개념

수치해석에서는 근사해를 계산하는 것뿐 아니라 계산 결과의 신뢰성을 평가하는 것이 중요합니다.

| 개념 | 의미 | 간단한 예 |
|---|---|---|
| **오차(Error)** | 실제 값과 근사값의 차이 | 1.414 대신 1.41 사용 |
| **수렴성(Convergence)** | 계산을 반복하거나 정밀도를 높일 때 해에 가까워지는 성질 | 이분법의 구간 축소 |
| **안정성(Stability)** | 계산 과정에서 작은 오차가 어떻게 전파되는지에 관한 성질 | 반올림 오차의 증폭 |
| **계산 비용(Cost)** | 계산에 필요한 시간과 메모리 | 반복 횟수와 연산량 |

예를 들어 이분법은 반복 횟수가 증가할수록 근을 포함한 구간이 좁아집니다. 이는 수렴성의 대표적인 사례입니다.

그러나 실제 컴퓨터에서는 모든 실수를 정확하게 표현할 수 없으므로 반올림 오차가 발생할 수 있습니다.

이러한 개념들은 이후 강의에서 각각 자세히 학습합니다.

## 1.6 Python으로 시작하는 수치해석

앞에서 살펴본 이분법을 Python으로 구현해 보겠습니다.

목표는 다음 방정식의 근을 구하는 것입니다.

$$
x^3-x-2=0
$$

### 1.6.1 알고리즘

```text
1. 근이 포함된 초기 구간 [a, b]를 정한다.
2. 구간의 중점 m = (a+b)/2를 계산한다.
3. 중점에서 함수값 f(m)을 계산한다.
4. 함수값의 부호를 확인하여 구간을 절반으로 줄인다.
5. 원하는 정확도에 도달할 때까지 반복한다.
```

### 1.6.2 Python 구현

```python title="introduction-bisection.py"
def f(x):
    return x**3 - x - 2


def bisection(a, b, tol=1e-8, max_iter=100):
    fa = f(a)
    fb = f(b)

    if fa * fb > 0:
        raise ValueError("양 끝점의 함수값은 부호가 달라야 합니다.")

    if fa == 0:
        return a
    if fb == 0:
        return b

    for i in range(max_iter):
        m = (a + b) / 2
        fm = f(m)

        if fm == 0 or (b - a) / 2 <= tol:
            return m

        if fa * fm < 0:
            b = m
        else:
            a = m
            fa = fm

    raise RuntimeError("허용오차에 도달하지 못했습니다.")


root = bisection(1.0, 2.0)

print(f"근사해: {root:.10f}")
print(f"함숫값: {f(root):.3e}")
```

전체 코드 내려받기: [introduction-bisection.py](/code/numerical/fundamentals/introduction-bisection.py)

**계산 결과 예시:**

```text
근사해: 1.5213797018
함숫값: -2.979e-08
```

이 코드는 근이 포함된 구간을 반복적으로 줄여 근사해를 계산합니다.

`tol=1e-8`은 구간의 중점을 사용할 때의 오차 상한을 기준으로 설정한 허용오차입니다. 계산 결과가 이 기준을 만족하면 반복을 종료합니다.

## 1.9 핵심 정리

이번 강의에서 학습한 내용을 정리하면 다음과 같습니다.

1. **수치해석**은 수학적 문제의 근사해를 계산하고 결과의 신뢰성을 분석하는 학문입니다.
2. **수치 알고리즘**은 수학적 문제를 컴퓨터로 해결할 수 있는 계산 과정으로 변환합니다.
3. **이분법**은 근이 포함된 구간을 반복적으로 줄여 근사해를 구하는 대표적인 알고리즘입니다.
4. **오차·수렴성·안정성·계산 비용**은 수치 알고리즘을 이해하고 평가하는 핵심 개념입니다.
5. 수치해석은 구조해석, 유체역학, 광학, Mesh Generation 등 다양한 과학·공학 분야에 활용됩니다.
