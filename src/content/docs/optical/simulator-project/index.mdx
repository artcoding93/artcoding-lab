## 프로젝트 소개

광학 계측 강의에서 배운 원리를 하나의 **브라우저용 교육 시뮬레이터**로 직접 구현하는 프로젝트입니다. 각 Phase는 광학 계측 학습 로드맵의 강의와 연결되어 있어, 강의에서 만든 계산 코드가 곧바로 시뮬레이터의 한 부분이 됩니다.

모든 측정 기술은 같은 구조로 다룹니다. 시료의 매개변수 $\mathbf{p}$(두께, 굴절률, 높이 등)에서 측정 신호를 계산하는 **정방향 모델(Forward Model)** $F$를 만들고, 측정 신호에서 $\mathbf{p}$를 거꾸로 찾는 **역문제(Inverse Problem)**를 최적화로 풉니다.

$$
\mathbf{y} = F(\mathbf{p}) + \boldsymbol{\varepsilon}, \qquad
\hat{\mathbf{p}} = \arg\min_{\mathbf{p}} \sum_{i} \bigl[\, y_i - F_i(\mathbf{p}) \,\bigr]^2
$$

- $\mathbf{y}$: 측정 신호(예: 파장별 반사율), $\boldsymbol{\varepsilon}$: 노이즈와 측정 오차
- $F_i(\mathbf{p})$: $i$번째 측정점(예: 파장 $\lambda_i$)에서 모델이 예측한 신호
- $\hat{\mathbf{p}}$: 측정값과 모델의 차이를 가장 작게 만드는 추정 매개변수

예를 들어 굴절률 $n_1$, 두께 $d$인 박막에서 윗면과 아랫면에서 반사된 빛은 다음 위상차를 갖고 간섭합니다(계면 반사에 의한 위상 변화는 Fresnel 계수에 포함).

$$
\delta = \frac{4\pi}{\lambda}\, n_1 d \cos\theta_1
$$

$\delta$에는 기하학적 두께 $d$가 아니라 광학적 두께 $n_1 d$가 들어가므로, 굴절률을 모르면 두께를 정확히 구할 수 없습니다. 이처럼 매개변수 사이의 상관관계와 측정 한계를 분석하는 것도 프로젝트의 중요한 목표입니다.

## 구현 범위와 데이터 원칙

| 구분 | 내용 |
|---|---|
| 박막 두께 | SR(반사율 분광), SE(분광 엘립소메트리) |
| 표면 형상 | WSI(백색광 주사 간섭계), PSI(위상 이동 간섭계) |
| 높이·계면 | Confocal, Chromatic Confocal |
| 단층·위상 영상 | OCT(A-scan·B-scan), DHM(디지털 홀로그래피 현미경) |
| 역해석 | 최소제곱·비선형 최적화, 정답 비교, 노이즈·불확도 분석 |

- 시뮬레이터는 **정답을 알고 있는 합성 데이터**를 기본으로 사용합니다. 추정값을 실제 설정값과 비교해 알고리즘의 정확도를 확인할 수 있습니다.
- 실측·표준시료 데이터 검증은 Phase 7 이후의 **별도 확장 단계**입니다. 실측 데이터는 출처와 측정 조건을 함께 밝히고 합성 데이터와 구분해 표시합니다.
- 실제 장비를 대체하는 측정 소프트웨어가 아니라, 측정 원리와 계산 알고리즘을 학습하기 위한 도구입니다.
