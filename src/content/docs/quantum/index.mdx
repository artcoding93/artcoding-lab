**양자 세계에서 양자컴퓨팅까지.** 빛과 전자의 이중성, 이중슬릿 실험처럼 흥미로운 양자 현상에서 출발해 물리적 직관을 쌓고, 쉬운 수학으로 양자 상태를 표현한 뒤 큐비트·양자 게이트·양자회로·알고리즘을 시각화와 시뮬레이터로 체험합니다.

**학습 흐름** 양자 현상 → 쉬운 수학 → 큐비트 → 양자회로 → 알고리즘 → Python 시뮬레이터 → 웹 시뮬레이터 → 현실과 미래

**대상과 선수 지식** 고등학교 수학(함수, 확률, 벡터의 기초)과 과학(빛과 파동)을 배운 학습자라면 시작할 수 있는 고등학교~대학교 교양 수준의 과정입니다. 미적분학과 선형대수학은 미리 알 필요가 없으며, 필요한 수학은 Part II에서 그림과 간단한 계산으로 익힙니다. Part VI(Python 양자 시뮬레이터)부터는 변수·리스트·함수·반복문 등 **Python 기초 지식**이 필요합니다.

<details>
<summary>난이도와 강의 유형</summary>

| 난이도 | 수준 |
|---|---|
| 고교 | 파동, 확률, 기본 함수와 벡터의 직관으로 이해하는 양자 현상 (Part I) |
| 고교~대학 교양 | 복소수, 벡터, 확률진폭 등 쉬운 수학을 그림과 예제로 도입 |
| 대학 교양 | 복소수·2×2 행렬·벡터 연산을 필요한 범위에서 직접 계산 (Part III~VI) |
| 프로젝트 | 배운 내용을 웹 기반 양자 시뮬레이터로 구현 (Part VII 등) |

| 유형 | 의미 |
|---|---|
| A 개념 | 현상과 물리적 직관을 중심으로 설명합니다. |
| B 수학 | 쉬운 수학적 표현과 간단한 계산을 중심으로 다룹니다. |
| C 시뮬레이션 | 시각화와 시뮬레이터로 직접 실험합니다. |

한 강의가 A+C처럼 여러 유형을 함께 가질 수 있습니다. 로드맵의 각 강의에 유형과 한 줄 학습 목표를 표시했습니다.

</details>

<details>
<summary>이 로드맵의 학습 방식</summary>

- 각 강의는 도입 질문이나 실험 → 현상과 물리적 직관 → 핵심 개념과 쉬운 수학 → 그림과 인터랙티브 체험 → 양자컴퓨팅과의 연결 → 핵심 정리 순서를 기본으로 합니다.
- 고급 증명, 추상적인 힐베르트 공간의 엄밀한 전개, 복잡한 슈뢰딩거 방정식 풀이는 다루지 않습니다. 수식은 개념을 이해하는 데 필요한 만큼만 사용합니다.
- 예를 들어 큐비트 상태 $\lvert\psi\rangle = \alpha\lvert 0\rangle + \beta\lvert 1\rangle$에서 $\alpha$, $\beta$는 확률진폭이고, 측정했을 때 0이 나올 확률은 $\lvert\alpha\rvert^2$입니다. 두 확률의 합 $\lvert\alpha\rvert^2 + \lvert\beta\rvert^2 = 1$이 정규화 조건입니다.
- 중첩은 '여러 결과가 동시에 확정되어 있는 상태'가 아니며, 측정 결과는 관측자의 의식과 무관합니다. 얽힘은 측정 결과 사이의 상관관계로, 이를 이용해 빛보다 빠르게 정보를 보낼 수는 없습니다.
- 양자컴퓨터가 모든 문제를 빠르게 푸는 것은 아닙니다. 속도 향상은 특정한 문제에서만 기대할 수 있습니다.
- Python 코드는 모든 강의에 넣지 않고, 계산과 시뮬레이션이 학습에 도움이 되는 강의에서 사용합니다.

</details>
