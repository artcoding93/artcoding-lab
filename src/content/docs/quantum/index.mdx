양자역학의 기초 개념부터 양자 게이트와 알고리즘까지, Python 실습과 인터랙티브 시각화를 통해 이해하고 나만의 양자회로 시뮬레이터를 완성합니다.

**학습 흐름** 양자 개념 이해 → 필요한 수학 → Python 실습 → 양자 게이트 → 양자회로 → 시뮬레이터 구현

<details>
<summary>이 로드맵의 학습 방식</summary>

- 양자역학이나 물리학을 전공하지 않은 학습자를 대상으로, 양자컴퓨팅에 꼭 필요한 개념만 다룹니다.
- 수식보다 개념적 이해와 시각화를 먼저 다루고, 복잡한 유도는 '심화 설명'으로 분리합니다.
- 모든 주요 개념은 Python NumPy로 계산하는 작은 예제와 연결합니다. 학습 초기에는 양자 SDK를 사용하지 않습니다.
- 예를 들어 큐비트 상태 $\lvert\psi\rangle = \alpha\lvert 0\rangle + \beta\lvert 1\rangle$은 복소수 두 개를 담은 NumPy 배열이고, 측정 확률 $\lvert\alpha\rvert^2 + \lvert\beta\rvert^2 = 1$은 이 배열의 정규화 조건입니다.

</details>
